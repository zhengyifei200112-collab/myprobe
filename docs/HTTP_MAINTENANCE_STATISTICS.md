# HTTP 维护排除统计

需求基线：后续开发文档第 6、17.3、18.5 节。属于 SVC-03，完整 M1–M5 范围不变。
状态：服务集成开发分支已实现并有本地测试与真实 Agent/浏览器验收，待评审、合并及发布；不能以这些证据代替完整 M3/M1–M5 交付。

## 统计口径

按单个服务、单个观测节点的已保留、已知计划和成熟时间范围统计。以计划槽的 scheduled_at 判断维护，包含开始、不包含结束；检查完成或通知发送时刻不决定该槽是否排除。

冻结成员含该节点的窗口形成有效区间：`[max(starts_at, created_at), min(ends_at, canceled_at))`，没有取消时取原结束。创建时间保留纳秒、窗口起止和取消沿用现有毫秒精度。区间为空不排除；重叠与相邻有效区间先合并，逐计划槽只扣一次。

取消前的维护历史仍有效，取消时刻起不再排除。取消一个重叠窗不解除另一个。现有窗口不可原地编辑；改窗使用“取消旧窗 → 预览并创建新窗”，保留旧的有效段，新窗从其创建时刻生效。新建后补填更早开始时间不能改变创建前的历史。统计按请求时读取的持久窗口快照重算，不从通知取消数或事件静默反推。

维护只扣已知计划槽；没有计划的时段不会增加分母。服务禁用、节点取消关联、周期/配置版本变化、保留边界和 126 秒成熟期继续遵循原统计契约。缺失与未执行也可属于被维护排除的计划槽，不能只删除失败样本来提升成功率。

## 计数与 API

原始计数、维护排除计数均包含 expected/success/failure/unobserved/missing。missing 为 expected − success − failure，unobserved 是 missing 的子集。选用维护排除口径时，选中计数逐项等于原始计数减排除计数。成功率仍为 success/(success+failure)，覆盖率为 (success+failure)/expected；零分母为 null，不能显示 100%。这不是连续时间 SLA 或外部合同达标保证。

GET `/api/v1/admin/service-monitors/:serviceID/statistics` 增加 `exclude_maintenance=true|false`。省略为 false，保留旧调用口径；管理页面默认勾选排除并明确传参，可切回原始。响应的 maintenance_excluded 标识实际返回口径，不根据请求开关推定成功。始终返回 raw 与 maintenance_excluded_counts 以及固定 maintenance_policy，供核对原始与排除量。无窗口时可返回排除口径、排除量为零。

保持管理员鉴权、no-store、最长 31 天与 5 秒查询期限；拒绝重复或非法参数。计划版本、任务结果、原始与排除计数、维护窗口及冻结成员在一个 SQLite 读取事务中获得。查询上限沿用 10000 计划版本、100000 候选结果，并最多读取 1000 个候选维护窗口；超限失败，不返回静默截断的统计。

不增加公开节点字段、Agent 协议或数据库迁移；使用现有持久窗口与计划表。完整数据库备份恢复继续保留窗口、取消、冻结成员、计划与结果。统计只读，不生成事件或通知，也不改变当前服务健康。

## 验收要求

- 人工固定槽核对原始、排除和选中计数，覆盖成功、失败、未执行、完全未派发和零分母。
- 精确开始/结束/取消/创建边界；纳秒计划槽与毫秒窗口；跨时区、重叠、相邻、取消前未开始、进行中取消、改窗和补记窗口。
- 服务周期/版本/关联变化、成熟期、保留截断、历史计划未知、不同观测点隔离。
- 读取前后检查原任务/结果不变；完整备份恢复后统计一致；快照与查询上限和索引证据。
- API 权限、no-store、非法/重复参数、默认原始与显式排除、隐私过滤。
- 页面开关清除旧数据，展示原始/排除量、全排除时零分母、错误及过期范围；明暗主题 360/768/1440 px，既有服务与告警回归。
