# 服务告警配置迁移

独立 `myprobe-service-alerts` v1 包迁移已配置服务的故障通知、证书提醒开关、触发/恢复/重复/冷却参数。基础配置继续支持 v1/v2 导入，v3 仅增加网络请求 family/包数；主机策略和本服务告警包保持原契约。先导入/创建服务定义，再创建目标通道，最后显式映射此包。服务和通道 ID 只作为来源引用，不能按同名或同 ID 自动绑定。

导出仅包含服务/通道别名、来源 ID、源 Provider 和告警参数。不含目标、地址、断言、凭据、密文、模板、事件、证书去重账本、历史任务或待发送队列。零配置允许导出空包，但不能提交空导入。初版至多 1000 服务和 1000 通道引用、2 MiB 请求；每个服务有且只有一个目标设置，两个来源不能映射同一目标服务。多个来源通道可明确映射同一目标通道；跨 Provider 映射允许，预览必须展示变化。

预览为真正只读快照，返回逐项旧/新参数、目标服务与通道状态、创建/更新数量及 digest。所有来源引用必须完整且无额外映射。目标必须存在；服务修订、告警修订与更新时间、通道发送修订/名称/类型/启用状态参与预览绑定。没有配置的目标明确显示“新建”；已有配置会完整覆盖选中的参数，其他服务不变。启用提醒可能在下一轮评估依据已有新鲜故障或证书产生通知；通道停用、服务停用、服务端未启用执行分别提示，导入不启用 HTTP 执行或新建网络任务。

应用在同一 SQLite 写事务内取得管理写锁，先查请求回放，再重新读取并比较预览状态，复用单服务保存的校验和修订栅栏。任何冲突、未知引用或写失败整批回滚；digest 是内容绑定，不是权限令牌或对象预留。成功设置与请求回放记录原子提交。只更新告警设置，下一轮同步规则；旧事件、已授权尝试、实际回执、维护/静默、共享等待及证书去重保持既有生命周期规则，不能把配置迁移当成历史恢复。

独立迁移 037 保存请求 ID、完整请求 digest、原结果和提交时间。相同请求/相同内容返回原结果，即使目标后来被修改或删除也不重写；同键异内容返回 409。全库最多 10000 条永久回放记录，超限拒绝新请求，既有回放继续可用。完整数据库备份保留这些身份；导出告警包不含它们。

管理员 API 使用 no-store、会话/CSRF 校验及 30 秒期限：`GET /api/v1/admin/service-alert-transfers/export`、`GET /destinations`、`POST /preview`、`POST /apply`。输入拒绝未知字段、多份 JSON、非法/缺失参数和不支持版本；错误/审计只含安全代码、计数与内部 ID。目标列表完整读取至多 1000 服务/通道，超限失败而非隐式截断。

管理页提供文件导入、显式映射、逐项预览、确认覆盖和结果。文件/映射修改使预览失效；发出应用前将完整原请求存入浏览器 sessionStorage。响应丢失、5xx 或刷新保留同一请求，冻结内容并允许“确认上次结果”，不能自动生成新键重复覆盖。存储不可用则不发送；损坏记录阻止提交并提示核对后清除，清除不会撤销已提交的配置。401/403 保留待确认请求，重新登录后仍可确认。

来源服务、通道和预览各按 25 项分页；来源支持名称/ID 搜索及已选择/未选择过滤。目标使用一个共用对话框，支持名称/ID/Provider 搜索、25 项分页、ID 与停用状态核对，并阻止其他来源已经占用的服务目标。选择、搜索和翻页不丢失文件其他项的映射，服务端始终预览及原子应用完整批次。

“下载映射模板”导出当前明确选择，未选择项为空。填写目标 ID 后可上传 `myprobe-service-alert-mapping` v1 文件，至多 2 MiB；该文件是管理页辅助格式，不是新增服务端 API。例子：

```json
{
  "format": "myprobe-service-alert-mapping",
  "version": 1,
  "services": { "source-service": "destination-service" },
  "channels": { "source-channel": "destination-channel" }
}
```

必须同时提供 `services` 和 `channels` 对象，每类最多 1000 项，可为空。未列出的来源保留现有选择，空字符串清除该项；所有键必须引用当前来源文件，非空值必须在重新读取的目标目录中存在。未知字段/版本/引用、重复目标服务或不合法结构使整份映射不生效，原选择保留，但旧预览失效；需修正并重新预览。多个来源通道仍可明确选择同一目标通道。不按名称或相同 ID 自动配对，模板可含内部引用与别名，分享前应核对用途。

待确认缓存 v2 只保存完整原请求、原请求 ID、预览 digest 和创建/更新计数，不复制逐项预览。恢复后明确说明没有重建旧预览；已提交请求返回原结果，未提交请求仍核对原预览版本。仍兼容旧版包含完整预览、没有 version 字段的缓存，并校验其逐项结构。缓存的服务/通道状态不作为当前状态；全局执行开关通过当前目标目录重新读取，读取失败时不推断为关闭。服务参数导出、目标目录和预览均不读取通道密文或 HTTP 目标规格。

验收包括跨库导出/映射、禁用和仅证书配置、Provider 变化、空包/未知版本/遗漏与额外字段、服务映射冲突、预览后修改或删除引用、并发同键/异键、原子回滚、完整备份回放和 v1/v2 兼容。浏览器在浅色/深色与 360/768/1440 px 验证覆盖预览、丢失响应/刷新/同键确认、旧缓存兼容、存储不可用及错误清空。1000 项显式映射、完整事务、恢复与分页证据见 [容量记录](SERVICE_ALERT_CAPACITY.md)。真实 Agent 验证导入设置经过原评估/Outbox 产生故障与恢复；全系统容量、24 小时运行、真实 OAuth/Provider 和发布门槛仍保留原路线。
