# 网络质量对比页面（NET-02）

公开面板、管理中心及登录后的密码分享页增加“网络质量”入口。它们共用一个比较界面，
使用各自授权 API；管理视图允许隐藏节点，密码分享只展示所有者明确选入的节点。
本轮正在重新整合并验证准确源，不把历史浏览器截图或CI作为当前通过依据。
完整NET-02、协议地址族/包数和最终运行容量仍须分别验收。

界面可选 1—8 个观测节点，选择授权目标别名，按需读取一个批量时序响应。节点变化后
先更新目标范围，再请求一次时序；不逐节点或逐点请求。控件变更清除旧结果，取消旧请求，
响应修订标识阻止过期结果覆盖新选择。关闭/失效会话退出时取消请求、释放图表/观察者并
恢复入口焦点。相同节点集合可复用已载入目标，分页由用户显式加载，不能无界自动拉取。

## 授权目标发现

三个既有 `/network-quality` 路径增加 `/targets`，只接受重复 node_id 及可选 cursor。
最多八个不同节点，每页 128 条，以 kind/ID 做稳定 keyset 翻页；cursor 绑定节点集合及
公开/管理/分享上下文，但不是授权凭据。每页都重新检查当前可见性或分享启用/成员。
响应固定为 id/name/kind 别名列表、next_cursor、page_size 和 observed_at，不返回地址、
端口、任务或冻结定义。撤销当前分配后仍可发现保留历史；全部历史过期后不再列出。

## 指标与时间解释

三个对齐图分别为成功样本平均 RTT（ms）、已执行失败率（%）和覆盖率（%）。空值保持
间断，不能连线填平或画成 0 ms；覆盖率真实为零时仍可显示 0%。淡红统计时段表示至少
一个显示节点在该桶存在执行失败，不代表整个桶持续故障。图例可切换节点而不重发请求。
汇总表显示覆盖率、执行失败率、P50/P95、范围抖动及成功/失败/缺测计数。近似分位数
加 ≈ 并提供误差边界；没有分母或可信样本显示 —。折叠说明列出实际可用范围和计划计数。

观测方向始终是“节点 → 目标”。地址族没有协议证据时写“未上报”，精确 ICMP 丢包率
不可用，不能根据目标字符串或失败分类猜测。TCP 失败也不标成丢包。
新协商结果在汇总表增加观测 IPv4/IPv6 任务数和未知数、ICMP 包丢失率及有计数/未知
任务覆盖。时间点提示使用同一点证据。部分覆盖明确标“部分观测”，不冒充全范围精确值；
包数按实际已发包加权，不平均任务百分比，TCP 显示不适用。无包证据不显示虚构的已发零包。
手机保留表格横向滚动，固定节点列；统计解释始终说明旧记录保留未知。

支持滚动 1h/12h/1d/3d/7d/30d/1y、最近已完成的当地 19:00—23:00 晚高峰及自定义范围。
晚高峰以目标列表返回的 Server 时间确定，避免客户端时钟领先产生未来区间。
自定义时间按选定 IANA 时区转换为带偏移的绝对时刻；夏令时不存在/重复时刻明确拒绝，
可改用 UTC 选择唯一时刻。测试覆盖跨天、夏令时跳时/重复、无效日期和未来/倒置范围。
结果同时展示日期、时分秒和 IANA 时区，后端仍按 UTC 半开范围读取。
