# 表单单位与现有告警流程集成（M1 / UX-03）

本分支复用原 #45 的金额、单位与到期时间实现，并与 #86 的可移植测试基线及其依赖
中的维护、范围策略、知悉、静默、聚合、HTTP 服务和系统健康功能整合。不是完整
M1—M5 交付；首页发现、批量管理、排序和节点详情仍须分别整合及验收。

## 用户行为

- 节点价格使用十进制金额和币种，精确转换为整数最小单位。USD、JPY、KWD 分别按
  各自小数位处理；零金额可保存。切换币种保留输入金额，不做汇率换算；无法表示的
  小数在输入旁说明并阻止提交。公开详情的价格也保留安全整数上界的精确分位。
- 月付、季付、半年、年付、一次性与自定义周期并存，旧自定义字符串不改写。
- 到期时间显示浏览器本地时区，保存为 UTC。未编辑的时间保留原始秒数及绝对时刻，
  不因 datetime-local 隐藏秒数或夏令时重复小时发生改变。
- 旧规则和范围策略都可切换带宽、流量及持续/恢复/重复/冷却时间单位。B 为字节，
  b 为比特；Mbps/GB/TB 使用十进制，MiB/s/GiB/TiB 使用二进制，选项旁说明换算。
- 范围策略保留聚合等待与“恢复持续时间跟随触发”的独立语义。重复提醒 0 继续表示
  使用冷却间隔；API 省略该零字段时按既有契约解释，不伪造另一个重复时间。
- 换单位保持整数原值；61 秒不能精确表示为有限小数分钟时保留秒并提示。
  超过 JavaScript 安全整数的输入明确拒绝，不静默取整。服务端限制继续生效。
- 扩展节点编辑框在视口内滚动，窄屏恢复窗口复选框保持正常尺寸和可操作性。

没有新增 API/Agent 字段或 SQLite 迁移。金额仍为整数最小单位、带宽为字节/秒、
流量为字节、规则时间为秒。旧后台的所有货币除以 100 的展示方式会修正为各币种
小数位；不是修改历史价格整数。隐藏节点及公开 DTO 权限边界不变。

## 可重复验证

使用 Node 22+、Go 和 Playwright，先执行：

```sh
npm --prefix web ci
npm --prefix web test
npm --prefix web run build
go build -o /private/myprobe-form-units-server ./cmd/server
mkdir /private/form-units-results
PLAYWRIGHT_MODULE=/absolute/node_modules/playwright \
node scripts/run-form-units-qa.cjs /private/myprobe-form-units-server /private/form-units-results
```

使用可写的新结果目录。Windows 默认使用本机 Edge，Linux 默认使用已安装的
Playwright Chromium；PLAYWRIGHT_BROWSERS_PATH 可指定独立缓存。
运行器只在 loopback 启动临时 Server，生成仅内存使用的合成密码和密钥，禁用自动
版本查询，结束时关闭拥有的进程。规则渠道为不可投递的自有回环合成目标；不点击
发送测试、不配置真实 Provider。手动调用浏览器脚本同样只允许 loopback 地址。

四项数学回归覆盖小数、0、USD/JPY/KWD、bit/byte、非法单位、安全整数边界及公开
金额精度。真实 Server 流程验证旧价格/自定义周期/到期秒数、币种切换拒绝无效小数、
规则和策略的持久化及再次保存不变；浏览器时区设为 America/New_York，覆盖含秒的
重复小时输入。节点、规则、策略三种表单分别在 360/768/1440 px 明暗主题运行，共
18 组截图，同时检查横向溢出及节点编辑框的视口边界。

保留的范围策略契约另跑六组明暗/宽度，覆盖恢复窗口、未覆盖的编辑、版本冲突、
删除确认、规则跳转至所属策略及应用失败提示。它使用合成 API 响应，与前面的真实
Server 持久化证据分别解释。CI 在既有浏览器 job 中运行两套验证并保留筛选后结果。
