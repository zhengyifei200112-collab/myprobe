# 脱敏诊断预览与下载（SYS-03）

系统健康页增加“导出脱敏诊断”。管理员先生成并检查固定快照，再下载 JSON。
这是运维统计与状态的诊断文件，不是配置迁移、数据库备份或远程命令执行功能。
依赖备份分支 #61 的 `1f37dfe` 以及原健康/服务栈，尚未合并或发布。

## 内容和隐私边界

格式为 `myprobe.diagnostics.v1`。Collector 使用明确的导出 DTO，不把健康 API、
SiteSettings、节点列表、任意 observer map 或其他完整运行对象直接序列化。

| 包含 | 含义及边界 |
| --- | --- |
| 版本 | 主/次/补丁号；移除可选 v 前缀，预发布/构建标签仅保留布尔标志；dev/ci 单独分类，其他值不可用 |
| 配置结构 | HTTP 探测、Cookie、可信代理条目数量、密钥/独立秘密文件/origin 是否配置，以及有效的正保留时长；不包含地址、路径、凭据或其他配置内容 |
| 配置数量 | 用户、节点、延迟目标/组、HTTP 服务、通知渠道、规则/策略的数量 |
| Agent 版本 | 已保存握手的归一化版本分布；最多 32 种，未识别、无握手和溢出分别计数；不证明当前通道的版本 |
| 数据库 | 三位迁移编号、日志模式、分配/可复用字节、主文件/WAL 大小及其可用/不存在/不适用状态；不复制数据库内容 |
| 任务与工作线程 | 保留、通知评估、两个调度器、手动备份生成及每日备份工作线程；缺少观察器时不可用，状态/错误文字仅来自闭合枚举 |
| 活动队列 | 故障逻辑行、聚合组与独立系统提醒的 pending/due/future/inflight/过期租约计数；故障逻辑行包含聚合成员，不与组相加 |
| 通道数量 | Agent v1/v2/未识别连接、普通待回报/过期结果、HTTP 宽限和浏览器订阅数；不包含会话或节点标识 |

固定排除：凭据、密码、令牌、会话/CSRF、渠道密文、完整数据库、备份口令/密钥、
文件路径、地址/目标 URL、名称/备注/主机名、通知正文、审计内容和任意版本标签原文。
归一化版本不会回显标签内的 IP/私有文本。可信代理、origin 和秘密文件仅报告结构
或布尔值，不报告实际地址/路径。预览里显示包含/排除范围，可展开实际文件内容。

计数是已知零值或不可用两种独立状态。配置数量来自一次只读 SQLite 事务；数据库
元数据、活动队列、进程状态及连接来自各自观察，不构成跨系统原子快照。
计数不读取历史样本、认证数据或消息正文，不更新状态、不领取任务、不处理过期
租约、不 checkpoint/VACUUM。连接导出使用全局锁及 HTTP 状态的尝试锁；繁忙时
保留未知，不等待网络 I/O，也不返回伪零。其他进程短锁和观察器不是全局原子快照。

## 预览与文件一致性

- 准备时生成最终 UTF-8 JSON 字节，冻结在当前 Server 进程内。预览提供文件名、
  大小、SHA-256、到期时间和完整内容。下载不会重新读取数据；预览后源状态变化
  不改变文件，重新生成才产生新快照。
- 绑定当前管理员 **登录会话 ID**，不是只绑定账号。另一个会话即使是同一账号
  也不能读取；下载时重新校验有效会话和 CSRF。JSON、元数据和文件中不包含该
  会话 ID、Cookie 或 CSRF。
- 有效期 5 分钟，内存期限保留 Go 单调时间分量；Server 重启后全部丢失。
  上限 32 份、每份 128 KiB，到期记录在下一次访问时清理；满额返回 429，不自动
  挤掉仍有效预览。不能通过请求添加原始内容或指定字段/文件路径。
- UI 在过期时禁止下载；服务端仍独立验证。已过期、重启或其他会话的读取统一
  返回 404，重新预览。文件大小与 SHA-256 响应头必须符合预览；浏览器在 Web Crypto
  可用时还计算实际下载字节哈希。不匹配不生成下载链接。
- 审计是下载的必需前置步骤；写入失败返回 503，不释放文件，也不设置附件头。
  成功记录 `export / diagnostic_bundle`、预览 ID、格式、大小、哈希与
  `response_prepared`。这是响应准备证据，不保证浏览器保存或用户分享成功。

准备操作采用 8 秒请求预算，各数据库查询有 2 秒子预算；超过准备预算不创建预览。
下载审计限 5 秒。页面请求限 12 秒，取消/离开页面会终止请求。没有后台自动导出或
自动上传；用户应检查内容后自行决定如何分享文件。

## API

两条路径均先设置 `Cache-Control: private, no-store`，然后校验管理员会话与 CSRF。
请求 JSON 最大 2048 字节，拒绝未知字段、尾随 JSON 和原始内容选项。

| 方法/路径 | 请求 | 响应 |
| --- | --- | --- |
| POST `/api/v1/admin/system/diagnostic-exports/preview` | 无选项，通常 `{}` | `preview` 元数据与 `bundle`；200，容量满 429，采集不可用 503 |
| POST `/api/v1/admin/system/diagnostic-exports/download` | `{"preview_id":"32位小写十六进制ID"}` | 200 JSON 附件和 `X-Content-SHA256`；失效/跨会话 404，审计失败 503 |

未登录/会话失效为 401，CSRF 失败为 403，非法请求为 400。错误响应也是 no-store。
预览可在有效期内重复下载，每次都重新认证和记录审计；不延长期限。错误不包含
SQLite 原始信息、路径或请求秘密。UI 的 401/403 清除预览并退出；健康或节点诊断
自身收到 401/403 也会卸载导出面板，避免仍显示旧的私有文件内容。

## 验证范围

已有针对性证据：预览字节拷贝隔离、SHA/大小匹配、并发总容量、到期回收、跨会话
拒绝、字段/标签隐私、32 种版本上限及独立未知计数、配置查询不改变元数据、锁繁忙
不返回零、严格请求/权限/缓存、源变化后文件仍保持预览状态、审计写失败不释放文件。

opt-in `TestLiveDiagnosticExportMainBrowser` 构建并启动真实 main Server，以临时库和
合成身份验证登录、真实工作线程、预览、后续数据变化、实际浏览器下载字节与哈希、
审计及会话撤销；明暗与 360/768/1440 px。受控 Vite 脚本
`scripts/diagnostic-export-ui-acceptance.cjs` 检查到期、503、校验和不符、重试、
CSRF 与 401/403 清除。最终完整本地、CI 和渲染结果必须按对应提交记录。
